BATTLE CITY CLONE (27.07.2026)

ОБЗОР
- Жанр: 2D Top-Down Shooter / Arcade
- Референс: Battle City (NES, 1985)
- Цель игрока: Уничтожить все вражеские танки на уровне, защищая свою базу.



ТЕХСТЕК
- Движок:      Unity 6.
- Рендер:      URP (2D Renderer), Pixel Perfect Camera, Sprite Atlas.
- Уровень:     2D Tilemap, Grid System, Composite Collider 2D.
- Физика:      2D Physics (Kinematic Rigidbody2D для сущностей, Triggers для проверок).
- Ввод:        Input System (New).
- Звук:        Audio Mixer (Master/SFX/Music), стандартные AudioSource.
- UI:          Уровень: Тайлы
               Меню: uGUI (Canvas).
- Оптимизация: Встроенный UnityEngine.Pool для пуль, взрывов и врагов.
- Данные:      ScriptableObjects для настроек танков и уровней.
- Сохранения:

  ИГРОВЫЕ МЕХАНИКИ
  - Сетка (Grid): Поле боя 26x26 клеток. Танки занимают 2x2 клетки. 
                  Движение и коллизии привязаны к сетке.
  - Движение: 4 направления. Танк не может повернуть, если не выровнен по сетке (snapping).
  - Стрельба: Лимит 1 пуля на ствол (улучшаемо до 2). Пули сталкиваются друг с другом.
  - Типы блоков:
       -- Кирпич: Разрушается пулями (частями).
       -- Сталь: Не разрушается (разрушается только бонусом).
       -- Вода: Непроходима для танков, пули летят над ней.
       -- Лес: Танки и пули проходят, но скрывают спрайты (рендерится поверх).
       -- Лед: Танки скользят (нельзя остановиться, пока не врежешься).
       -- Враги: Появляются в 3 точках сверху. Максимум 4 врага на экране одновременно.
       -- База (Орел): Находится внизу в центре. Разрушение Орла = мгновенный Game Over.
       -- Бонусы (Power-ups): Выпадают из красных танков. (Звезда, Каска, Часы, Лопата, 
                              Танк, Граната).

ОСНОВНЫЕ КЛАССЫ И СУЩНОСТИ
  1. Core / Managers:
     - GameManager — синглтон, управляет потоком игры (пауза, конец игры).
     - LevelManager — читает данные уровня, спавнит тайлмапу и Орла.
     - GridManager — хранит матрицу клеток, проверяет занятость, отвечает за разрушение тайлов.
     - SpawnManager — логика появления врагов (очередь, таймеры, точки спавна).
     - AudioManager — проигрывание звуков через пул AudioSource.
     
 2. Entities (Сущности):
     - TankBase (Abstract) — общее для всех танков (здоровье, скорость, стрельба, 
                             привязка к сетке).
     - PlayerTank — наследуется от TankBase, добавляет ввод, жизни, апгрейды.
     - EnemyTank — наследуется от TankBase, добавляет ИИ, тип брони (обычный, быстрый, 
                   бронированный).
     - Bullet — движение по сетке, проверка коллизий, вызов эффектов.
     - Base (Eagle) — принимает урон, триггерит Game Over.
     
 3. Data (ScriptableObjects):
     - TankStatsData (скорость, кулдаун стрельбы, кол-во пуль).
     - EnemyTypeData (цвет, здоровье, шанс выпадения бонуса).
     - LevelData (массив чисел или строк, описывающий карту).



РОАДМЭП
M1: Прототип движения. 
    Настройка сетки, движение танка по клеткам, повороты, камера.

M2: Стрельба и коллизии.
    Пули, пул объектов, столкновение пуль со стенами и друг с другом.

M3: Террейн и разрушаемость.
    Настройка Tilemap, разрушение кирпича, разные типы блоков.

M4: Враги и ИИ.
    Спавн врагов, простой ИИ (случайное движение + стрельба по таймеру).

M5: Игровой цикл.
    Условия победы/поражения, жизни, защита Орла.

M6: Бонусы и Полишинг.
    Power-ups, звук, UI, экраны меню, сохранение рекордов.
